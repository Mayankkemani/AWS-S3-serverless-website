# Day 3 - AWS S3 Static Website Hosting

## What I Did
1. Created S3 bucket with public access
2. Uploaded index.html and error.html  
3. Enabled Static Website Hosting
4. Disabled "Block all public access"
5. Added bucket policy for public read
6. Got website live on S3 endpoint

## S3 Website URL
https://mayank-cloud-engineer-1778994398.s3.ap-south-1.amazonaws.com/index.html

## Key Learnings
- S3 can host static websites without EC2
- Bucket policy needed for public access
- index.html is default document
- error.html for 404 pages
- Very cheap hosting option

## Tech Stack
AWS S3, HTML, CSS
